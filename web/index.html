FIELD GUIDE / QUICK START

Teach. Measure. Repeat.

  1. Make a connection. The browser streams actual MuJoCo geometry. Each tab has its own world.
  2. Drop a treat. Click the ground, then select Find a treat. WASD lets you steer manually; Space asks Miso to stay.
  3. Train a fresh policy. In the repository, run the command in Experiments. Choose curious, gentle, or zoomies; use a unique participant/run name.
  4. Bring it to the yard. Refresh Experiments, then select the checkpoint in the policy menu. Learned policies were trained for flat forward motion; turning and object interactions can fail.
  5. Look at evidence. Read docs/BENCHMARKS.md and docs/STATUS.md. A trained checkpoint is not proof of a solved behavior.

The arena brain is a trained 247k-parameter transformer receiving RGB, text and numeric state. Its six plan rows are replanned every half simulated second; each displayed chunk is a fixed one-second proposal. Voice uses offline English command transcription: check the transcript, then Send. PPO supplies straight-trot residuals; walk, run, hop, steering and contact-gated magnetic retrieval use analytic controllers. The camera is a dedicated overhead sensor, not Miso’s eyes. The puppy is stylized original artwork. No training or paid infrastructure starts from this page.
